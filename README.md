# Zomata-Analysis
Zomato Restaurant Insights 
Description: Analyzed restaurant data (pricing, location, services, ratings), Developed KPIs and created a 
dynamic dashboard with different visualizations to assess performance. The dashboard enabled strategic      
analysis for decision-making. 
❖ Skills Demonstrated: 
•  Data Transformation 
•  Exploratory Data Analysis (EDA) 
•  Data Visualization 
•  KPI Development & Dashboard Creation 
❖ Tools Used: Tableau, Power BI, Advanced Excel, SQL.  
❖ Insights Gained & Business Impact: 
•  Identified high-profit regions to guide marketing and expansion strategies. 
•  Analyzed ratings to uncover opportunities for improving customer satisfaction and retention. 
•  Evaluated sales performance to refine strategy and drive business growth.
